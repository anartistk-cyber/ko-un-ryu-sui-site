# flowcloud.net / glow-izumiotsu.jp  public_html/.htaccess  への追記案（2026-11-07・flowcloud.net は適用済み＝本番で画像に Cache-Control: public, max-age=2592000 を確認／glow-izumiotsu.jp も適用済み＝glow_img-08.jpg に同じヘッダーを確認）
# 目的: 画像（写真）を、再訪問のお客様のスマホ・PCに30日間保存しておき、2回目以降の表示を速くする。
# 現状: 写真に「どれくらい保存してよいか」の指定が無く（PageSpeed『効率的なキャッシュ保存期間』の指摘・FCの旧WP写真など約80KB）、毎回取り直している。
# 効果: 再訪問・同じサイト内の別ページに移るときの表示が速くなる（初回は変わらない）。HTML は htaccess-html-revalidate の指定どおり『開くたびに更新確認』のまま。
# 注意: 同じファイル名で写真を差し替えると、再訪問の方には最大30日間、古い写真が出ることがある。差し替えるときは別のファイル名にする（このサイトの build は新しい写真に新しい名前を付ける運用）。
# 貼る場所: ファイルの一番下（FLOWCLOUD は "###X SUPPORT" ブロックの外）。
# 手順: ①今の .htaccess をバックアップ ②下の「ここから」〜「ここまで」を末尾に貼る ③保存 ④サイトが表示されること（500でないこと）を確認 ⑤異常ならこの追記だけを消して再保存
# ============================================================

# ---- ここから ----
<IfModule mod_headers.c>
  <FilesMatch "\.(jpe?g|png|gif|webp|svg|ico)$">
    Header set Cache-Control "public, max-age=2592000"
  </FilesMatch>
</IfModule>
