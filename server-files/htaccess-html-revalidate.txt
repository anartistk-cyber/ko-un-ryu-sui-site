# 目的: 更新したページが、お客様のスマホ・PCで古いまま表示されるのを防ぐ。
# 原因: 今は HTML に「どれくらい保存してよいか」の指定がなく、ブラウザが更新日時から推測して数時間〜数日、古い画面を使い回す。
#       （採用サイト ko-un-ryu-sui.com は htaccess-new-domain に同じ指定が入っているため起きない）
# 効果: HTML だけ「開くたびに更新の有無を確認」にする。変更がなければサーバーは「更新なし(304)」と返すだけなので軽い。
#       CSS・画像は今まで通り保存（CSSは ?v= の番号で更新される）。
# 貼る場所: ファイルの一番下（FLOWCLOUD は "###X SUPPORT" ブロックの外）。ブロックの中には入れない。
# 手順: ①今の .htaccess をバックアップ ②下の「ここから」〜「ここまで」を末尾に貼る ③保存
#       ④サイトが表示されること（500エラーでないこと）を確認 ⑤異常ならバックアップに戻す
# 注意: .htaccess は sync_fc.php / sync_gl.php の同期対象外。藤津さんがXserverの「.htaccess編集」で貼る（保存は藤津さん）。
# ============================================================

# ---- ここから ----
<IfModule mod_headers.c>
  <FilesMatch "\.html?$">
    Header set Cache-Control "no-cache"
  </FilesMatch>
</IfModule>
