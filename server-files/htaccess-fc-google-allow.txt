# 目的: 国外IP制限（"###X SUPPORT" ブロック）が Google の検査ツール等を 403 で弾くのを直す。
# 原因: そのブロックは「日本のIP」か「UAに Googlebot / bingbot 等を含むもの」だけを許可し、
#       Google-InspectionTool（Search Console の URL検査・インデックス登録リクエスト）などは対象外。
# 貼る場所: ファイルの一番下（"###---" で終わる X SUPPORT ブロックの外）。ブロックの中には入れない。
# 手順: ①今の .htaccess をバックアップ ②下の「ここから」〜「ここまで」を末尾に貼る ③保存
#       ④サイトが表示されること（500エラーでないこと）を確認 ⑤異常ならバックアップに戻す
# 注意: このファイルは sync_fc.php では配信されない（.htaccess は同期対象外）。藤津さんがXserverで貼る。
# ============================================================

# ---- ここから ----
# Search Console URL inspection / live test / request indexing
SetEnvIf User-Agent "Google-InspectionTool" AllowSearchBot
# Google crawl address block (Prefetch Proxy, GoogleOther, Storebot etc. also come from here)
Allow from 66.249.64.0/19
# ---- ここまで ----

# ---- AI検索系クローラー許可（2026-11-04 藤津さん承認・保存済み）----
# 検索・回答用のみ通す。学習用（GPTBot / ClaudeBot / CCBot 等）は通さない。
SetEnvIf User-Agent "OAI-SearchBot" AllowSearchBot
SetEnvIf User-Agent "ChatGPT-User" AllowSearchBot
SetEnvIf User-Agent "PerplexityBot" AllowSearchBot
SetEnvIf User-Agent "Perplexity-User" AllowSearchBot
SetEnvIf User-Agent "Claude-SearchBot" AllowSearchBot
SetEnvIf User-Agent "Claude-User" AllowSearchBot
SetEnvIf User-Agent "Applebot" AllowSearchBot
# 注: UA指定は偽装可能。より厳密にする場合は OpenAI（openai.com/searchbot.json 等）・Perplexity（perplexity.ai/perplexitybot.json 等）の公開IP範囲での許可も可能（要定期更新）。Anthropicは公開IP範囲なし。

# ---- PageSpeed Insights（Lighthouse）許可（2026-11-05 22:06 入力 → 藤津さんが保存済み。22:14 PSIで403が解消し測定できることを確認）----
# 目的: PageSpeed Insights の測定が海外IP制限で 403 になり、FLOWCLOUDだけ表示速度を測れないのを直す（測定専用・サイトの見た目や順位は変わらない）。
# 貼る場所: 上の「AI検索系クローラー許可」と同じブロックの末尾（"###---" の外）。保存は藤津さん。
SetEnvIf User-Agent "Chrome-Lighthouse" AllowSearchBot
# 注: UA指定は偽装可能だが、公開の美容室サイトを海外から1ページ見られる程度の影響で、リスクは小さい。
