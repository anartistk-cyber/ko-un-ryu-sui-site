# 目的: 国外IP制限（"###X SUPPORT" ブロック）が Google の検査ツール等を 403 で弾くのを直す。
# 原因: そのブロックは「日本のIP」か「UAに Googlebot / bingbot 等を含むもの」だけを許可し、
#       Google-InspectionTool（Search Console の URL検査・インデックス登録リクエスト）などは対象外。
# 貼る場所: ファイルの一番下（"###---" で終わる X SUPPORT ブロックの外）。ブロックの中には入れない。
# 手順: ①今の .htaccess をバックアップ ②下の「ここから」〜「ここまで」を末尾に貼る ③保存
#       ④サイトが表示されること（500エラーでないこと）を確認 ⑤異常ならバックアップに戻す
# 注意: このファイルは sync_fc.php では配信されない（.htaccess は同期対象外）。藤津さんがXserverで貼る。
