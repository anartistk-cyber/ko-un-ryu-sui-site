# 会社案内PDFの文字直し（pdf_fix）

会社案内2027（軽量版）.pdf のように、元データ（作成アプリ）が手元に無いPDFの文言を直すための道具。2026-11-12 に使った。PDF本体はリポジトリに入れない（Drive の同じファイルを新バージョンにする）。

## しくみ
- 本文は Identity-H の CID フォント（Adobe-Japan1）。ASCII の文字 c は CID = c−31（例：'8'=0x19、'9'=0x1A）。
- 同じフォントの CID を差し替えると、元と同じ見た目になる（build_pdf.py）。フォントは軽量化のため使う字だけの部分集合なので、含まれない字（例：「火」）は上に重ね書き（build_pass2.py の Noto Sans JP 部分集合）。
- Noto の OTF(CFF) は MuPDF の insert_text で CJK が描画されない → TrueType に変換（otf2ttf.py）。
- 確認は MuPDF（PyMuPDF）で描画。poppler は CID 本文を正しく描かない。QR は cv2.QRCodeDetector で読む。
- `save(garbage>=3)` で xref 番号が振り直される。パス間では `page.get_contents()` / `get_images()` で取り直す。

## 使い方
1. 各スクリプト先頭の `/path/to/work` を作業フォルダにする。作業フォルダ内：`pdf/`（元PDF）・`pdftools/`（このスクリプトとフォント）・`pdfedit/`（出力）。
2. `dump.py` / `dump2.py` でページの文字列（CID・位置）を読み、直す箇所の置換を `build_pdf.py` に書く（`rep()` は出現回数が1でないと止まる）。
3. `python3 build_pdf.py`（pass1）→ `python3 build_pass2.py`（重ね書き・QR）→ 必要なら `build_pass3.py`（追加の直し）。
4. 描画して前後のピクセル差が直した箇所だけか、テキストが正しいか、リンク・QRを確認。
5. Drive：ファイルの「⋮ → ファイル情報 → 版を管理 → 新版をアップロード」で同じファイルを差し替える（共有リンク・LINEメニューのリンクは変わらない）。右クリックメニューは位置がずれて「ゴミ箱に移動」を押しかけたことがある。必ず行の「⋮」から、1段ずつ画面で確認して進める。
6. Noto 部分集合フォントは `pyftsubset`（fonttools）で、使う字だけから作る（Noto Sans JP・OFL）。
