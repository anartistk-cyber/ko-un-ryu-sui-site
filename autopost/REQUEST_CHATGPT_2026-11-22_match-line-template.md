## 今の状態（Claude が公開ページのコードで確認）
- LINEへのリンクは **1か所だけ**：結果画面（`#results` の `.actions`）の `a.button.line`「LINEで相談する ↗」（診断を終えるまで表示されない。トップ付近にLINEリンクは無い）。
- `https://line.me/R/oaMessage/%40512rmwnk/?<文>` で、文は「マッチング診断を受けました。見学について相談したいです。」の1文だけ。
- 結果画面に出ている情報：`#score`（価値観のマッチ度の目安）、`#salon-result`（あなたのいいところ）、`#salon-caption`、`#result-tip`。診断の種類は `tracks[track].label`（美容学生・新卒 など）。

## やってほしいこと
LINEを開いたとき、トークの入力欄に **記入用の文面** が入っているようにする（あとは空欄を埋めて送るだけ）。
LINE の URL は、LINE ID（`%40512rmwnk`）の後ろに `/?` をつけ、文面を `encodeURIComponent` した形。改行は `\n`（`%0A`）。`@` は必ず `%40`。

### ① 診断の前（トップ付近のリンク）
```
【採用のご相談】
①ご希望：新卒／中途／パート／学生アルバイト
②お名前：
③ご質問・見学のご希望日など：
```

### ② 診断のあと（結果画面のリンク）＝診断の内容も入れる
結果を表示するとき（結果画面を出す処理の中）に、`a.button.line` の `href` を毎回作り直す。診断の種類は選んだもの（`tracks[track].label`）、結果は画面に出ている値をそのまま使う。
```
【採用のご相談】
①ご希望：{tracks[track].label}
②お名前：
③マッチング診断の結果：価値観のマッチ度 {#score の表示}／いいところ「{#salon-result の表示}」
④ご質問・見学のご希望日など：
```
例：
```
【採用のご相談】
①ご希望：美容学生・新卒
②お名前：
③マッチング診断の結果：価値観のマッチ度 82%／いいところ「技術力（向上心）」
④ご質問・見学のご希望日など：
```
- 入れるのは結果の見出しだけ。**一人ひとりの回答（どの選択肢を選んだか）は入れない。** 名前・連絡先・学校名なども入れない（空欄を本人が埋める）。
- 「回答を見直す」「最初から」を押して結果が変わったら、リンクも作り直す（古い結果が残らないように）。
- 実装の例（変数名はアプリに合わせてよい）：
```js
const LINE_OA = "%40512rmwnk";
const lineUrl = (lines) => "https://line.me/R/oaMessage/" + LINE_OA + "/?" + encodeURIComponent(lines.join("\n"));
```

## 守ること
- 文面の先頭は「【採用のご相談】」のまま（採用サイト本体と同じ。LINE側で見分けやすくするため）。
- 「診断結果：」で始まる文や「行雲流水＋名前」の形にしない（LINE の自動応答・スタッフ登録に当たってしまうため）。
- リンクの `data-` 計測属性・見た目（CSS）は変えない。
