- /autoresponse 応答メッセージ一覧（**「利用」スイッチで有効か確認する**。編集画面の文面だけでは有効かわからない。2026-11-09 に glow の Default が実はオフだったのを見落とした）

## 操作のコツ
- 画像のアップロード：リッチメニュー作成の「画像 選択」→「画像をアップロードして適用する」→ 隠しの file input を `find` で探し、`file_upload` でクラウド側のPNG（リポジトリのパス可）を渡す → 「背景全体の画像を適用」→「適用」→ 確認の「適用」。2500×1686（6分割）。画像は autopost/line-richmenu/（HTML＋render.cjs で書き出し）。
- 領域ごとの「タイプ」は `form_input` で「リンク」を選び、URL欄とアクションラベル（20字以内）を `form_input` で入力。リンクには UTM（utm_source=line&utm_medium=social&utm_campaign=richmenu）を付ける（UTM_LINKS.md）。
- 表示期間は必須。終了日は 1年先（2027/11/08 まで入った）まで可。**採用メニューは 2027/11/08 23:59 で終わるので、2027-10 に延長・作り直す。**
- 自動返信のスイッチは、ページ上の見た目のスイッチを座標でクリック→「利用を開始しますか？」の確認で「利用開始」。
- 応答メッセージ一覧の上部「現在のステータス」は、応答方法に応答メッセージが含まれるかを示すだけ。個別の文面が有効かは別。
- javascript_tool の出力にクエリ文字列（? = &）を返すと遮断されることがある。URLは `split('?')[0]` などで切って返す。
